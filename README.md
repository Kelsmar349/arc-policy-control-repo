# 🛡️ GRC Policy & Control Repository

This project is a practical showcase of Governance, Risk, and Compliance (GRC) concepts using sample policies, control mappings, risk management documentation, and compliance readiness checklists.

It is designed to demonstrate my understanding of key GRC responsibilities and help others learn how to build out GRC programs in small businesses or enterprise environments.

---

## 📂 What's Included

| Folder | Contents |
|--------|----------|
| `/policies` | Security policy templates (Acceptable Use, Password Policy, Remote Work) |
| `/controls` | NIST 800-53 control mapping to internal policies |
| `/risk-register` | Sample risk register with mitigation strategies |
| `/compliance-checklists` | ISO/IEC 27001 compliance readiness checklist |

---

## 🧠 Skills Demonstrated

- ✅ Writing and organizing cybersecurity policies  
- ✅ Mapping controls to compliance frameworks (e.g., NIST, ISO 27001)  
- ✅ Building and maintaining a risk register  
- ✅ Preparing compliance documentation and gap assessments  
- ✅ Using GitHub to manage and version-control documentation

---

## 🚀 Use This Repo To

- Kickstart a GRC documentation program for your own projects
- Learn the fundamentals of GRC as a cybersecurity student or analyst
- Prepare for compliance assessments like SOC 2 or ISO 27001
